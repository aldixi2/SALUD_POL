Actualizar datos del convenio

Genera un nuevo data.json a partir del Excel actualizado, sin tocar el dashboard.

Cómo usarlo

  1. Selecciona abajo el Excel actualizado (debe tener las hojas CONSOLIDADO y Transferencias, con las mismas columnas de siempre).
  2. Presiona "Procesar Excel" y revisa el resumen que aparece.
  3. Presiona "Descargar data.json".
  4. Reemplaza el archivo data.json de tu repositorio en GitHub por este nuevo archivo y súbelo (commit + push).
